# 正本から再実装できるか監査する

- **着手・再開時**に、[core-story-first](../core-story-first/SKILL.md)で選んだ用途と、[architecture-refinement](../architecture-refinement/SKILL.md#常時適用)で特定した契約を対象にする。[再実装に必要な記録](../../../docs/policies/文書作成規約.md#再実装に必要な記録)から既存の正本と未解決の指摘をたどる。
- **指示・判断・実装・観測が変わった時**は、担当に、その変更の根拠と結果を所有元の見出しへ反映させる。単独作業では自分で更新する。
- **検証後・各作業の区切り・引継ぎ前**に、主担当が[再実装の監査](../../../docs/policies/文書作成規約.md#再実装の監査)を実施する。文書だけで振る舞いと合否を導き、差分・証跡と照合する。不足は該当の正本と判断できない具体例を示して修正を促し、修正後に同じ例で再監査する。残る指摘は再開条件まで引き継ぐ。
