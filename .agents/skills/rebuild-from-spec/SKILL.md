# 正本から再実装できるか監査する

- **着手・再開時**に、[core-story-first](../core-story-first/SKILL.md)で選んだ用途と、[architecture-refinement](../architecture-refinement/SKILL.md#常時適用)で特定した契約を対象にする。[再実装に必要な記録](../../../docs/policies/文書作成規約.md#再実装に必要な記録)から既存の正本と未解決の指摘をたどり、対象の振る舞いと合否を文書だけで判断できるか確かめる。
- **指示・判断・実装・観測が変わった時**は、担当が、何をなぜ変え、どうなったかを、その仕様や検証結果を管理する文書に書く。更新や要約の後は、主担当が[次の読者が同じ意味に読めるか](../../../docs/policies/文書作成規約.md#次の読者が同じ意味に読めるか確かめる)を元の指示と照合する。スキル自身の指示文も対象にする。単独作業では自分で書いて読み直す。
- **検証後・各作業の区切り・引継ぎ前**に、主担当が[再実装の監査](../../../docs/policies/文書作成規約.md#再実装の監査)を実施する。文書だけで振る舞いと合否を導き、差分・証跡と照合する。
- **必要な記録が欠けている、または言葉を略したために判断が分かれると気づいた時点で**、その記述をもとに進める開発を保留する。主担当は[監査の停止・再開条件](../../../docs/policies/文書作成規約.md#監査の停止再開条件)に従い、担当に正本を直させ、同じ例で再監査する。合格後に開発を再開する。
