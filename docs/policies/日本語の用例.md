# 日本語の用例

技術文書の言葉を選ぶときは、読者が何を見て、何を判断するのかを確かめる。ここでは2024年8月1日を境に、公開時期が分かる日本語資料を比較した。古い資料に用例が1つあれば、その意味で当時使われていたことが分かる。どの程度使われていたかを判断するには、同じ意味を別の言葉で表した例も数える必要がある。

## 同じ意味の候補から表記を選ぶ

2024年7月31日までに、同じ場面を同じ読者に説明した資料を比べる。先に意味・候補・資料の選び方・数える単位を決める。同じ資料の転載や改訂で引き継いだ文章は一度だけ数える。ほかの表記や併記も記録し、調べた対象全体の半数を超えた表記をその用途に採用する。最近の資料での増減は別に記録する。

同数、過半数なし、比較に使える資料が乏しい場合は「判断保留」とし、何が足りないかを書く。正式名称、原文の引用、コードの識別子は元の資料で照合する。一般向け画面で色を示す場面と、開発者が手法の名前を説明する場面は別に数える。

### 表示に使う基本色の名前

画面や機器に現れる色の説明を対象に、次の3資料から色名を調べた。1資料につき1色1票とし、指定した箇所で同じ表記が繰り返されても票は増やさない。

| 公開資料と確認箇所 | 赤系の色名 | 緑系の色名 |
|---|---|---|
| IPAのアジャイル開発ガイド（2013年3月）、3.2.3節の脚注5でテスト結果に対応する表示色 | 赤 | 緑 |
| NTT西日本のINSメイトV30Slim取扱説明書（2018年9月）、25ページのACTランプが点灯するときの色 | 赤 | 緑 |
| Python 3.7.17の日本語マニュアル（2023年6月）、端末の定数 `COLOR_RED` と `COLOR_GREEN` に対応する色名 | 赤 | 緑 |

赤系は「赤」が3件、「レッド」が0件。緑系は「緑」が3件、「グリーン」が0件だった。この3資料で多かった表記をRideComの表示色に採用する。テストの成否を報告する文では「失敗」「成功」と結果を書く。IPAの同じ脚注でカタカナを使う箇所は開発手順の名前なので、表示色の件数に含めていない。[IPAの脚注5](https://www.ipa.go.jp/archive/files/000026849.pdf#page=56)、[NTT西日本のランプ一覧](https://www.ntt-west.co.jp/kiki/support/pdf/v30s_documents_1809.pdf)、[Pythonの表示色の一覧](https://docs.python.org/ja/3.7/library/curses.html#constants)

## 同じ意味で使われた割合

分母には、同じ分野・読者・意味について、同じ単位で抽出した対象を数えた。分子には、そのうち該当の表現が一度以上使われた対象を数えた。

| 誰が何を読むか | 数える単位と表現 | 基準日より前 | 基準日以降 |
|---|---|---|---|
| 自治体のシステム担当者が、仕様書の改訂を識別する | 仕様書本編1冊につき、表紙の改訂番号が「第2.3版」の形式 | 2022年8月から5冊中5冊 | 2025年末までの3冊中3冊 |
| Pythonの開発者が、端末に表示する色を指定する | 定数 `COLOR_RED` の日本語の色名が「赤」 | 3.7.17で1件中1件 | 3.13.15で1件中1件 |
| 同じ開発者が緑色を指定する | 定数 `COLOR_GREEN` の日本語の色名が「緑」 | 3.7.17で1件中1件 | 3.13.15で1件中1件 |
| FreeBSDのメールサーバー運用者が、宛先ホストの決まり方を調べる | 該当節の本文1段落につき、メール配送の動作をその語で説明 | 2023年12月の2段落中2段落 | 2025年2月の2段落中2段落 |
| 宅配便の再配達が事業者に及ぼす影響を調べる | 国土交通省の同じ定期調査の発表1件につき、荷物を届ける最後の区間について、調査報告にある語を使用 | 2023年の2件中0件 | 2025年の2件中2件 |
| 公証手続の利用者が、どの書面を請求できるかを調べる | 公正証書の正本と謄本、それぞれの書面の交付請求を定める箇所で、その書面の名称を使用 | 2023年の条文で各1件中1件 | 2025年の条文で各1件中1件 |
| ドメイン名の紛争当事者が、手続の結果を読む | 日本語で作成された判断文書1件につき、本文の表題が判断の名称と一致 | 2022年の6件中6件 | 2025年の4件中4件 |
| PostgreSQLの運用者が、サーバーから送れなかった理由を調べる | 送れなかったことを示すエラーメッセージ1項目につき、日本語訳に「送信」を含む | 16.0の8件中6件 | 17.0の8件中6件 |
| 同じ運用者が、サーバーで受け取れなかった理由を調べる | 受け取れなかったことを示すエラーメッセージ1項目につき、日本語訳に「受信」を含む | 16.0の7件中5件 | 17.0の7件中5件 |

物流の発表で表現が現れた割合は異なった。比較したのは各年2件なので、物流業界全体の語の増減は判断できない。色の定数名や公正証書の書面は、各時期に各1項目を確認しただけである。一般的な使用率を推定する資料には足りない。

紛争の判断文書と仕様書の表紙には、それぞれ同じ機関の書式がある。FreeBSDの説明は同じ本文を引き継いでいる。PostgreSQLの2つのリリースでは、表で比べた英文15件が共通する。同じ文章の再掲を、別の書き手が独立にその表現を選んだ回数には数えない。

テスト結果を色だけで伝える場合、アプリの通知が端末に届く場合、開発チーム内で文書の優先順や設計を決める場合については、当時と今の使用率を比較していない。

## 同じ条件で数え直す方法

### 仕様書の改訂番号

デジタル庁の「各種仕様書ダウンロード」で、自治体の情報システムの共通機能を定めた仕様書の本編を選ぶ。初回の2022年8月31日から2025年12月31日までに公表された本編8冊が対象。各PDFの表紙から改訂番号を1つずつ読み、数字の全角・半角と空白の違いを除いて比較する。別紙と新旧対照表は数えない。[公開日と各PDFへのリンク](https://www.digital.go.jp/policies/local_governments/common-feature-specification)

### 端末の表示色

Pythonの日本語マニュアルで `curses` の定義済みの色を示す表を使う。3.7.17のページの更新日は2023年6月28日、比較した3.13.15のページは2026年8月16日。それぞれ8色のうち、同じ定数の行を1行ずつ対応させた。シアンやマゼンタの説明にも赤や緑が現れるが、別の色を説明する行なので除く。[3.7.17の色の表](https://docs.python.org/ja/3.7/library/curses.html#constants)、[3.13の色の表](https://docs.python.org/ja/3.13/library/curses.html#curses.COLOR_RED)

表示ページが更新されたときは、同じ時期の日本語翻訳で英語原文 `Red` と `Green` に対応する `msgstr` を確認できる。[3.7の翻訳記録](https://github.com/python/python-docs-ja/blob/e6596dc7e8bd070c04e6497f0d3ab23710a0651a/library/curses.po#L3327-L3344)、[3.13の翻訳記録](https://github.com/python/python-docs-ja/blob/155a1b5dc5fbb9359773b60d19b4b0079d4bc2f5/library/curses.po#L2814-L2823)

### メールを宛先に届ける仕組み

FreeBSDの日本語ハンドブックで、メール章の「Email と DNS」（`mail-dns`）から次の見出しまでを読む。宛先を説明する本文全2段落の各段落で、メール配送の動作をその語で表したかを数える。2023年12月20日と2025年2月18日の同章を比較すると、変わったのはページの設定のみで、対象の説明文は同一だった。[2023年の本文](https://github.com/freebsd/freebsd-doc/blob/258750c3a106ece99537dfadc9ed961c1571cf40/documentation/content/ja/books/handbook/mail/_index.adoc#L90-L98)、[2025年の本文](https://github.com/freebsd/freebsd-doc/blob/54ac237fdb34d9074316cd8f8a77832bd618e4f6/documentation/content/ja/books/handbook/mail/_index.adoc#L91-L99)

### 宅配便の調査報告

国土交通省が公表した宅配便の再配達率の調査から、2023年と2025年の4月・10月調査をすべて選んだ。対象は発表本文で、添付資料を除く。次に引用する表現を1回以上使う発表を数えた。2023年の本文は「再配達」と書いている。後の2件には、物流上の最後の区間を指す言葉もある。[2023年4月調査](https://www.mlit.go.jp/report/press/tokatsu01_hh_000694.html)、[同年10月調査](https://www.mlit.go.jp/report/press/tokatsu01_hh_000736.html)、[2025年4月調査](https://www.mlit.go.jp/report/press/tokatsu01_hh_000908.html)、[同年10月調査](https://www.mlit.go.jp/report/press/tokatsu01_hh_000956.html)

> ラストマイル配送

荷物の配送を表した古い実例には、ヤマト運輸と佐川急便が上高地地域で始めた共同事業がある。この発表は宅配便の再配達率を報告するものではないため、上記4件の集計から除いた。[2020年4月10日の両社の発表](https://www.yamato-hd.co.jp/news/2020/news_200410.html)

### 公正証書の交付請求

e-Gov法令検索で、2023年12月31日と2025年12月31日に施行されていた公証人法を開く。前者は第47条第1項と第51条第1項、後者は第44条第1項第1号と第43条第1項第1号に当たる。公正証書の正本の交付を請求する規定と、証書の謄本の交付を請求する規定を1件ずつ対応させた。文体が変わっても、2種類の書面は条文で区別されている。2025年10月施行の改正は2023年6月公布なので、施行後の本文から新しい書き手の選択は推定できない。[2023年の条文](https://laws.e-gov.go.jp/document?lawid=141AC0000000053_20230614_505AC0000000053)、[2025年の条文](https://laws.e-gov.go.jp/document?lawid=141AC0000000053_20251001_505AC0000000053)

### JPドメイン名の紛争処理

1. JPNICの一覧で、2022年と2025年の事件番号0001から0006を各年6件ずつ調べる。年・番号を固定すれば、一覧に新しい事件が追加されても対象は変わらない。[事件の全一覧](https://www.nic.ad.jp/ja/drp/list/all.html)
2. 各事件の判断文書を開く。2025年の0002は取下げ、0004は英語で作成されたため、日本語の判断文書の分母から除く。2022年の6件には該当する除外事由がない。[2025年0004の英語の文書](https://www.nic.ad.jp/ja/drp/list/2025/JP2025-0004.html)
3. 本文冒頭の表題を1回数える。表題内の空白を取り除き、次に引用した表題と一致するかを調べる。ブラウザーのタブに表示されるページ名は集計から除く。[2022年0001の本文](https://www.nic.ad.jp/ja/drp/list/2022/JP2022-0001.html)、[2025年0001の本文](https://www.nic.ad.jp/ja/drp/list/2025/JP2025-0001.html)

> 裁定

### PostgreSQLのエラーメッセージ

対象はPostgreSQL 16.0（2023年9月14日公開）と17.0（2024年9月26日公開）。各リリースのサーバー本体に含まれる日本語翻訳ファイルを使う。[公開日の一覧](https://www.postgresql.org/support/versioning/)、[16.0の翻訳](https://github.com/postgres/postgres/blob/REL_16_0/src/backend/po/ja.po)、[17.0の翻訳](https://github.com/postgres/postgres/blob/REL_17_0/src/backend/po/ja.po)

各ファイルを空行で項目に分ける。単数の英語原文（`msgid`）と日本語訳（`msgstr`）の引用符で囲まれた文字列を、項目ごとに連結する。ヘッダー、廃止項目、複数形、訳が空の項目、`fuzzy`指定の訳は除く。この時点で16.0が5,815件、17.0が6,125件になる。

英語原文の先頭に正規表現 `^could not send\b` または `^could not receive\b` が一致する項目を、大文字・小文字を区別せずに抜き出す。対応する訳に「送信」または「受信」があるかを数える。両リリースとも、送信側の残り2件は共有メモリのキューへの「送出」、受信側の残り2件は一覧を「受け取れませんでした」と訳している。

調査を追加する場合は、資料の公開日、対象読者、比較する意味、数える単位、資料の選び方、両期間の分子・分母を残す。片方に対象がない場合や、異なる意味を分けられない場合は、その意味での使用率を「未比較」と記録する。

## 技術的な操作を表す動詞

同じ英語の動詞でも、テストなら「実行する」、アプリなら「起動する」、既に起動したプレーヤーなら「再生を始める」と書き分ける。手順では開始する操作を、結果の報告では開始・終了・合否のうち実際に確かめた事実を書く。道を走る人や車の動作は、そのまま表せる。

Python 3.7.17（2023年6月公開）の日本語マニュアルは、テストの実行を管理する機能を説明している。通信の説明では、送信する対象と受け取る側を示している。これらは言い換えの用例であり、日常の動詞を技術用語として使う割合は未比較である。[当時の公開日](https://www.python.org/downloads/release/python-3717/)、[テストランナーの説明](https://docs.python.org/ja/3.7/library/unittest.html)、[HTTP接続の説明](https://docs.python.org/ja/3.7/library/http.client.html)

| 読者が見分けたいこと | 書き分ける内容 |
|---|---|
| 処理をいつ、何回行うか | 初回の実行、失敗後の再実行、決まった間隔での繰り返し |
| どの処理をどこに依頼するか | 関数を呼び出す、サーバーに要求を送る、相手の応答を受け取る |
| 誰に失敗が伝わるか | エラーを記録する、呼び出し元に伝える、画面に理由を表示する |

未登録の表現でも、別の担当者が同じ操作を選べるかを確かめる。複数の操作に読めるときは、観測記録や元の指示で意味を確かめてから、同じ使い方が文書や画面のほかの箇所にも残っていないかを調べる。
