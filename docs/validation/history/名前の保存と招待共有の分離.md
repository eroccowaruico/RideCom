# 名前の保存と招待共有の分離

## 指示と設計

2026-11-17。招待中に名前の確定・共有・終了の意味が分からず、OS共有を取り消せることも設計から漏れていたという利用者指摘に対応する。[状態遷移と一連の操作](../../design/招待と登録の設計.md#招待の作成)を先に定義し、HTMLの入力・保存済み詳細も更新した。共有取消・コピーを配達や登録成功と扱わず、画面を勝手に閉じない。

## 名前だけ保存する基盤

App工程。`SavedUser`の固定IDを先に明示保存できるschema 10を追加した。未登録の人はリモート識別情報を持たず、通話・グループ追加・通知許可の対象から除外する。招待の配送記録は`personID`で人へ紐づける。初回受諾は元のIDと呼び名を引き継ぎ、既存本人は既存IDと呼び名を保って重複を除く。表示名による統合はしない。期限切れ・削除・再送ACKでも名前だけの人を勝手に登録しない。
