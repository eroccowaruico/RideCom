| 同じ本人の新端末 | 通話鍵を新端末用の参照で保存した。起動時の通常読込と相手・グループを選ぶ操作から、双方が音声を受け入れた。iOS Simulatorでは個別・グループとも双方が試験用PCMパケットを受信した |
| 別アカウントの所有者・証明の期限切れ・本人の除外記録 | 保存処理が拒否した。相手・通話先の一覧と端末内の鍵は変わらなかった |
| 通話鍵を保存した後で一覧の確定に失敗 | 確定済みの一覧は変わらなかった。再読込で参照されない鍵を回収し、再試行で相手・通話先と鍵を保存できた。復元済みの保存先に同じ入力を渡しても上書きしなかった |

macOSは復元・グループの認証・保存の29件、iOS Simulatorは復元・保存・背景操作の18件が成功。いずれも標準の検証手順で、指定した試験がすべて実行されたことを照合した。証跡は `.validation/icloud-restore-store-20261122/`。

```sh
scripts/validate.sh macos \
  --only-testing RideIntercomTests/ReplacementDeviceRestoreTests \
  --only-testing RideIntercomTests/RegularGroupRepresentativeTests \
  --only-testing RideIntercomTests/GroupPersistenceTests
scripts/validate.sh ios \
  --only-testing RideIntercomTests/ReplacementDeviceRestoreTests \
  --only-testing RideIntercomTests/GroupPersistenceTests \
  --only-testing RideIntercomTests/BackgroundCallStorageTests
```
