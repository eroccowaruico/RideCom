## 復元要求の受諾IDを照合先の二つの保存と比べる

| 照合した操作 | 変更後の結果 |
|---|---|

| 古い要求を届ける。照合先の端末内は再登録後で、iCloudは再登録前または再登録後 | いずれも確認を返さなかった |
| 新しい要求を届ける。照合先の端末内は再登録後で、iCloudは再登録前 | 確認を返さなかった |
| 登録を照合するIDがない、または署名後にIDを書き換える | IDがない個別通話候補からは要求を作らない。IDを含まない要求には確認を返さず、IDの書き換えは署名エラーになった |

| 通話鍵を保存した後で一覧の確定に失敗 | 確定済みの一覧は変わらなかった。再読込で参照されない鍵を回収し、再試行で相手・通話先と鍵を保存できた。復元済みの保存先に同じ入力を渡しても上書きしなかった |
