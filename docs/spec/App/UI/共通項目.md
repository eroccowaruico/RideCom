# RideCom UI 共通項目

## 目的

本書は RideCom App の全画面で共通する UI 項目と表示方針を定義する。

## 共通定義

| 項目 | 内容 |
|---|---|
| アプリケーション名 | `RideCom`。App・Widget・Watch、通知、招待、権限説明、翻訳で統一する。技術識別子の扱いは[開発環境](../../../development/開発環境.md#開く入口)を参照する |
| ルート | `TabView` |
| 各タブ | `NavigationStack` |
| ローカルメンバー | `selectedGroup.members.first` を自分として扱う |
| リモートメンバー | `selectedGroup.members.dropFirst()` を相手一覧として扱う |
| メーター | `VoiceMeterView` は値文字列を直接出さず、レベルとピークを視覚表現する |
| URL 受理 | `rideintercom://join?token=...` を `onOpenURL` から[共通の招待受理](共通画面遷移.md#共通ルール)へ渡す。参加先の表示と進行中の通話を同じ規則で扱う |

## 共通タブ

| 項目名（日本語） | 項目ID | ラベル | 目的 | データ仕様 | 表示仕様 |
|---|---|---|---|---|---|
| 共通タブ | なし | なし | 一覧、診断、設定を役割ごとに分離する。通話はタブにしない | `AppTab` | 下部タブバーとして常時表示 |
| 通話 | `closeCallButton` / `callAccessoryOpenButton` | `Close` / 接続先の名前 | [通話画面の配置](Call.md#standardの通話ユーザーグループ)に従い、選んだ接続先の通話を開く。閉じた通話はiPhone・iPadの通話アクセサリ、またはMacのツールバーから開き直す | `AppTab.call`（タブとしては表示しない） | `chevron.down` / 状態の記号 |
| ユーザータブ | `usersTab` | `Users` | 直接招待関係の相手を選ぶ。最初のタブ | 固定文字列 | `person.2` |

## 一覧行の共通操作

StandardとAdvancedのUsers・通常グループの行は `destinationRowActions` を使う。行の末尾からのスワイプで操作を表示し、最後まで引いてもボタンの押下を待つ。Macの右クリックでは同じ操作を設定、削除の順に並べる。削除ボタンは `destinationDeleteConfirmation` で対象を確かめてから実行する。

両モードの相手の設定も同じ削除確認を使う。確認を開くときに呼び名、対象ID、現在のログインと通話、削除で切断するかを記録する。タイトルは「{呼び名}を削除しますか？」。その相手と接続中なら「今の接続は切断されます。」を表示し、確定のボタンを「切断して削除」にする。現在のログインや通話、削除による切断の有無が変わったらダイアログを閉じる。確定時も同じ条件を照合する。キャンセルでは設定や一覧に留まる。設定から確定したときは、保存に成功してから設定を閉じる。保存に失敗したらエラーを表示し、設定に留まる。

| 行 | 設定 | 削除 |
|---|---|---|
| 相手 | `User Settings`（`gearshape`） | 保存を編集できる場合に `Delete`（`trash`） |
| 通常グループ | `Group Settings`（`gearshape`） | 保存を編集できるオーナーに `Delete`（`trash`）。招待で入った相手はグループの設定から退出する |

一覧とグループ設定のメンバー行は、OSごとの表示に `trailingRowActions` を使う。

### グループ設定のメンバー行

| 操作 | Standard | Advanced |
|---|---|---|
| 名前を編集 | 行を押してメンバー詳細を開く。未登録の招待枠は招待の人物詳細へ進む | 行末の `Edit Name` で名前の画面を開く。未登録の招待枠は行を押して招待の人物詳細へ進む |
| グループから外す | 利用権がある間に行末で `Remove` を表示する。通常メンバーの詳細にも `Remove from Group` を表示する | 利用権がある間に行末で `Remove` を表示する。Macの右クリックでは `Edit Name`、`Remove` の順に出す |

両モードは `groupMemberRowActions` で利用権の判定と対象を共有する。Standardにある自分の行は表示専用。iPhoneとiPadでは行末のスワイプで、Macでは右クリックで項目を開く。最後までスワイプしても、項目を押すまでは確認を開かない。外す操作は画面側の `memberRemoveConfirmation` が相手の名前を含む標準の確認を開く。現在の確認はタイトルと「外す」「キャンセル」で構成する。保存時の再確認と結果は[グループ設定の仕様](Call.md#グループの設定と相手の設定)を参照する。

両モードの相手の行は、その時点のメンバーIDで `groupSettingsMember-{memberID}` を付ける。新しい相手の招待待ちは予約枠のIDを使う。署名付きの受諾を保存した後は、対応する予約枠に代わって、受諾した相手のIDで通常メンバーの行を表示する。

## 共通表示方針

| 項目 | 方針 |
|---|---|
| 接続と media | control plane と media plane を混同させない |
| 設定値と実効値 | requested と selected / applied を分ける |
| 環境差異 | package report の `ignored` は非対応 no-op として表示し、致命扱いしない |
| 失敗 | `failed` は Call のエラー文言、Diagnostics の severity、ログに反映する |
| 高頻度値 | 画面は要約値だけを表示する。ログ確認を前提にしない |
| 機密値 | group secret、invite token、鍵材料、音声 payload は表示しない |

Standardの短い通話・マイク状態とAdvancedの詳細表示は同じViewModelから導出する。詳細なmeterとruntime reportの表示解釈は以下のAdvanced項目に適用する。

## 表示解釈

| 表示 | 解釈 |
|---|---|
| Input メーター | ローカルは送信前入力、参加者カードは受信後デコード済み入力を示す |
| Output メーター | 最終出力へ回した音声を示す |
| Participants 状態 | 接続、認証、受信、再生を別軸で読む |
| Diagnostics Overview | 1 カード 1 層で、ぱっと見て現在起きていることを確認する |
